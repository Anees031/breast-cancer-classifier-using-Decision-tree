# 🚀 Get Started - Breast Cancer Classification

## Quick Start (3 Steps)

### Step 1: Install Dependencies
```bash
pip3 install -r requirements.txt
```

### Step 2: Run the Classifier
```bash
python3 breast_cancer_classifier.py
```

### Step 3: View Results
- Check console for detailed metrics
- Open `breast_cancer_analysis.png` for visualizations

**That's it! 🎉**
